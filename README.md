## 功能特性

### 核心功能

- **编辑** — 像素级绘图，支持铅笔、直线、矩形（圆角）、圆形、框选工具
- **导入/导出 PNG** — 支持缩放适配、居中裁剪、自定义缩放因子三种模式
- **导出 C 代码** — 生成 `PROGMEM const uint8_t` 格式的字节数组，直接嵌入 Arduino 项目
- **导出原始十六进制** — 纯十六进制文本，适用于自定义格式需求
- **实时预览窗口** — 放大显示当前像素，直观查看图标效果

### 图像处理

- **反色** — 黑白像素一键反转
- **旋转** — 左旋 90°、右旋 90°、旋转 180°
- **镜像** — 水平翻转、垂直翻转
- **圆角裁剪** — 圆弧裁剪（半径可调）或 WouoUI 原生圆角

### 编辑辅助

- **多步撤销/重做** — 记录操作历史，支持反复回退
- **复制/粘贴** — 复制当前图标并在需要时粘贴恢复
- **框选操作** — 框选区域后可用方向键移动位置，Space 键旋转选区
- **画布大小调整** — 可在 8×8 ~ 256×256 范围内自由调整，始终为正方形

```bash

# 2. 直接运行（无需安装任何依赖即可使用基础功能）
python icon_editor.py

# 3. 如需导入/导出 PNG，首次操作时会自动提示安装 Pillow

pip install Pillow
```

> **提示**：本工具为单文件应用，下载 `icon_editor.py` 即可运行，无需额外配置。

3. **Space** — 顺时针旋转选区内容

5. **Esc** — 取消选区

## 导入导出

### PNG 导入

支持三种导入模式：

| 模式 | 说明 |
|:-----|:------|
| **缩放适配** | 将图片缩放到画布尺寸（默认，NEAREST 采样） |
| **居中裁剪** | 从图片正中心裁剪画布尺寸区域 |
| **自定义缩放** | 按指定比例缩放后再居中裁剪/填充 |

> 导入时会将图片转换为灰度图，以 128 为阈值二值化，<128 视为黑色。

### PNG 导出

- 导出为 1 位色深的 PNG 文件
- 支持导出时放大（如 1×=48×48, 2×=96×96, 4×=192×192）

### C 代码导出

导出格式示例：

```c
PROGMEM const uint8_t icon[288] = {
    0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00,
    0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00,
    ...
};
```

> 每个字节的低位在前（LSB first），每行 16 字节。图标在 WouoUI 中使用 `u8g2.drawXBMP()` 绘制。

### 原始十六进制导出

纯十六进制文本格式，可用空格或逗号分隔，适合自定义解析场景。

## 常见问题

### 1. 无法导入/导出 PNG？

本工具依赖 **Pillow** 库处理 PNG 图片。首次导入/导出时会自动检测并提示安装，也可手动安装：

```bash
pip install Pillow
```

### 2. 画布尺寸如何计算？

数据按行逐字节存储，每行字节数 = `(宽度 + 7) // 8`，低位在前（LSB first）。

以 48×48 为例：`BYTES_PER_ROW = (48 + 7) // 8 = 6`，总字节数 = 48 × 6 = 288。

### 3. 导入 PNG 后图标不清晰？

导入时使用 NEAREST 采样进行缩放，以保留锐利边缘。如需更好的缩放效果，建议先在外部编辑器中将图片缩放到目标尺寸后再导入。

### 4. 如何在 WouoUI 中使用生成的图标？

将导出的 C 代码复制到 `menu_data.h`（或 `.cpp`）中，添加到 `main_icon_pic` 数组即可。使用 `u8g2.drawXBMP()` 函数绘制。
